# 🛋️ Furniture Project

A clean, simple app to browse, list, and buy furniture.

## ✨ Features
* **User Accounts:** Register, log in, and manage your profile securely.
* **List Furniture:** Upload items with pictures, prices, and descriptions.
* **Buy Furniture:** Find what you like, and contact the seller.
* **Dashboard:** Keep track of your active listings and your purchase history.

## 🚀 Quick Start
Get the project running locally in just a few steps:

```bash
# 1. Clone the repo
git clone [https://github.com/hinoobers/furniture-project.git](https://github.com/hinoobers/furniture-project.git)
cd furniture-project

# 2. Install dependencies
npm install

# 3. Start the app
npm start
